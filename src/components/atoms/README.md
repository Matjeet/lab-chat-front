# Atoms (átomos)

Bloques más pequeños e indivisibles de la interfaz. No dependen de otros
componentes de la aplicación.

Ejemplos: `Button`, `Input`, `Label`, `Icon`, `Text`, `Avatar`.

Reglas:

- Sin estado de negocio; como mucho estado de UI muy local.
- Reciben todo por props.
- No importan moléculas, organismos, plantillas ni páginas.
