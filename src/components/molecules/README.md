# Molecules (moléculas)

Combinaciones pequeñas de átomos que forman una unidad funcional reutilizable.

Ejemplos: `FormField` (label + input + error), `SearchBar`, `MessageBubble`.

Reglas:

- Pueden importar átomos.
- No importan organismos, plantillas ni páginas.
- Lógica mínima de presentación; los datos llegan por props.
