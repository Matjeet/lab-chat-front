# Organisms (organismos)

Secciones relativamente complejas de la interfaz, compuestas por moléculas y/o
átomos. Representan una parte reconocible de una pantalla.

Ejemplos: `Header`, `MessageList`, `ChatComposer`, `Sidebar`.

Reglas:

- Pueden importar moléculas y átomos.
- No importan plantillas ni páginas.
- Pueden tener algo de estado de UI, pero los datos entran por props.
