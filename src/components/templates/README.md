# Templates (plantillas)

Definen la estructura y disposición de una pantalla (dónde va la cabecera, el
contenido, la barra lateral...), pero sin datos reales: usan `children` y props.

Ejemplos: `DefaultLayout`, `ChatLayout`, `AuthLayout`.

Reglas:

- Pueden importar organismos, moléculas y átomos.
- No importan páginas.
- Sin lógica de negocio ni llamadas a datos.
